\textbf{Profile}\\
When the user clicks “Profile” on the navigation bar, the \emph{Profile screen} is displayed. Here, the user can see all his statistics related to his trips and the number of path published by this account.

\noindent
\textbf{Edit profile screen}\\
From the \emph{Profile screen}, when the guest clicks “Settings”, this screen is displayed. Here, the user can modify his username and password, or delete the account.
\begin{figure}[!h]
    \centering
    \includegraphics[width=0.6\linewidth]{DD/Images/Mockup/EditProfile.png}
    \caption{Edit profile screen}
    \label{fig:placeholder}
\end{figure}

\newpage
\noindent
\textbf{Login}\\
When the guest clicks “Login” on the navigation bar, the \emph{Login screen} is displayed. Here, the guest must enter their credentials in order to access their account and use all the services available to registered users (see the \emph{Home page} on the left).
\begin{figure}[!h]
    \centering
    \includegraphics[width=0.6\linewidth]{DD/Images/Mockup/Login.png}
    \caption{Login screen}
    \label{fig:placeholder}
\end{figure}

\newpage
\noindent
\textbf{Sign up}\\
From the \emph{Login screen}, when the guest clicks “Sign up”, this screen is displayed. Here, the user must enter their credentials and a username. Finally, the guest clicks “Sign up →”, the account is saved in the database, and the user is redirected to the \emph{Profile screen}.
